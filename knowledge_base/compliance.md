# Compliance

Customer data must be handled with least-privilege access. Support staff should only access data needed to resolve a documented customer issue.

Sensitive information such as passwords, payment data, access tokens, and private keys must never be requested over email. If a customer sends sensitive information, acknowledge receipt, avoid repeating the secret, and request secure rotation when appropriate.

Data deletion requests must be verified before action. Legal or compliance-related requests should be escalated immediately and should not be answered with speculative advice.

Audit logs should capture important system events, escalations, and automated recommendations.
